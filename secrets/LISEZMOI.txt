Secrets générés aléatoirement pour cette installation (secrets Docker).
- db_owner_password.txt : mot de passe du propriétaire de la base (migrations)
- db_app_password.txt   : mot de passe du compte applicatif à privilèges minimaux
- enote_master_key.txt  : clé maîtresse AES-256 (32 octets base64). NE PAS PERDRE : sans elle, notes et sauvegardes sont illisibles.
Pour une nouvelle clé : docker compose run --rm app node src/cli.js generer-cle
